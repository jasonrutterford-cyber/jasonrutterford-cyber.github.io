Agent Empathy Canvas

Like a UX empathy canvas, but the persona is an agent working on a person's behalf. Fill it in to find out which skills to write and which MCPs to build.

Agent

What is this agent called, and where does it run?

Acts on behalf of

Which person or role is it working for?

Task / job story

When [situation], I want the agent to [do], so that [outcome].

Trigger

What starts it? A request, an event, a schedule?

Purpose

Based on this task, what is the agent here to achieve? What does "done well" look like?

Do / Execute → skills

What actions does it need to take or complete?

Consume → MCPs

What data, documents and systems does it need to read?

Discover → MCPs

What does it need to find out, look up or check before acting?

Boundaries

What stays with the human? When must it ask, escalate or stop? What must it never do?

Process → skills

What does it need to transform, analyse, calculate or decide?

Inform → skills

Who does it need to tell, and what? Updates, notifications, records.

Explain → skills

What does it need to justify or make clear to the person — reasoning, confidence, options?

Skills to write

Instructions the agent needs. One per distinct capability: name — what it covers.

MCPs to build

Data feeds and tools the agent needs. One per system: name — what it exposes (read / write).

Success measures

How will we know the agent is doing the job well? Outcome, quality, time, trust.

How to read it: Purpose and Boundaries frame the agent. The six middle blocks are its needs. Needs tagged → skills become instructions; needs tagged → MCPs become data feeds. Click any box to edit. Edits save in this browser; use Export JSON to keep or share them.
